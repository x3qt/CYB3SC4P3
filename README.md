# CYB3SC4P3

The cyberscape of the city’s network drowns in a neon-lit web of data-transfer meshes. Glowing holoads rotate above impenetrable corporate databanks, hawking a future no one wants to buy. Data-transport vessels glide along the shimmering web, delivering precisely measured packets of encrypted information into fortified vaults. Corporate Watchdogs patrol the streets and trace intruders through the grid.

## Map data

The hosted game loads nine Minsk sector snapshots from [maps/](maps/). The extract was taken on 2026-11-24 from the [OpenStreetMap map API](https://api.openstreetmap.org/api/0.6/map?bbox=27.538%2C53.884%2C27.574%2C53.902). The JSON files include the road, building, and waterway geometry used by the game.
